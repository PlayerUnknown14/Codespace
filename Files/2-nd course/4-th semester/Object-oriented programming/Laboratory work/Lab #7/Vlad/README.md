# Браузер файлов — Лабораторная работа №7

## Требования
- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Visual Studio Code с расширением **C# Dev Kit**

---

## Как запустить

### 1. Откройте папку проекта в VS Code
```
File → Open Folder → выберите папку FileBrowser
```

### 2. Сборка и запуск через терминал VS Code
```bash
dotnet run
```

### 3. Только сборка
```bash
dotnet build
```

### 4. Публикация (готовый .exe)
```bash
dotnet publish -c Release -r win-x64 --self-contained true
```
Готовый файл появится в папке `bin\Release\net8.0-windows\win-x64\publish\`
